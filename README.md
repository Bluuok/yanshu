## 当前项目统一决策（基线共识）

1. **第一阶段材料实验试点，两条并列业务线**：可核验、可编辑且尽量少人工修改的论文初稿；可持续更新和提醒的动态实验规划。
2. **结果导向**：导师的 12 步是参考方法库，不强迫任务走满；不把审稿意见和作者全过程历史记录当作必需样本。
3. **真实证据与隐私优先**：A/B/C 资料分级；未经授权数据不外传。不存在原始实验数据时不伪造结果。
4. **首轮评测务实**：目前的 12 篇为候选论文，不等于已下载、核验过 12 套原始数据；评分维度/权重是待导师校准的建议，不宣称能预测论文发表。
5. **优先复用、只选一套主平台**：OpenScience 为**需要实际体验/源码验证的首选候选**，不是已经确认完成二开。OpenResearch 只作为计算实验的可选工具，腾讯 Hyra 2.0/Yunque 用于借鉴研究任务分层和监督机制；后备底座 DeerFlow 2.1 仅在主候选实测不通过时再评估。详见 [技术调研](docs/03-调研与复审/技术调研.md)。
6. **六阶段长期目标保留**：自动仿真、设备操作、受控 RSI 和个人科研 Bot 不强行纳入本期交付。

## 接下来推进流程

**先**对 [测试论文](docs/02-实施与评测/测试论文.md) 的一套材料实验论文做文件级验收 → **再**按 [选型与体验](docs/03-调研与复审/选型与体验.md) 用该案例体验 OpenScience，并用 [论文评分](docs/02-实施与评测/论文评分.md) 保留初稿质量/引用/计算的证据 → **然后**验证实际扩展接口、实验规划、权限和任务恢复 → **最后**决定是否正式 Fork 作为唯一主底座。

预算严格沿用建设总纲基线：**第一阶段总预算暂按约 12,000 元，首月现金采购上限 4,000 元包含在总预算内**；以实际报价及资源使用情况为准。
