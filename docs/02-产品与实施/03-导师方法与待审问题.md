## 导师科研流程与平台任务对照

> **资料性质**：本文件为根据导师方法整理出的**流程—平台职责对照稿**，并非导师提供的 12 步原始逐字文本。原始 `Response.docx` 及此前提到的完整科研边界问答尚未以原件纳入当前 GitHub 主分支；需要原件时应另行归档，不可据本表反向推定导师的逐字表述。

适用范围：材料实验类科研任务。导师的 12 步是研究活动参考，不是平台必须逐项执行的固定程序；不同课题可以跳过、合并、并行或反复返回。论文初稿与动态实验规划均为第一阶段重点，按当前课题目标和已有材料选择任务。第一阶段对科研软件和实体设备提供设计建议及真实结果导入，不自动操控仿真软件或实验设备。

| 导师原有环节 | 系统按需承担的工作 | 所需资料与成果 | 使用条件与核查 |
|---|---|---|---|
| 1 梳理研究思路 | 明确背景、问题、目标、方法、创新主张和限制，追问关键缺项 | 研究者思路、已有材料；形成课题卡 | 有明确课题时直接补全，不强求重新选题；主张由研究者确认 |
| 2 文献调研 | 检索、筛选、归类与溯源，比较方法与证据 | 关键词、公开或授权文献；文献表与证据记录 | 记录全文权限，题录或摘要不等于原文已核验 |
| 3 创新与研究问题 | 寻找相似工作、研究空白及差异，提出待验证观点 | 相关论文、研究思路；差异表与未确认事项 | 不保证穷尽文献或证明绝对首创，避免无依据弱化创新 |
| 4 研究方案 | 对照目标整理技术路线、约束、指标和可行性 | 研究目标、资源；研究方案和待决策点 | 根据已有方案调整；重大研究方向由研究者决定 |
| 5 理论与模型 | 汇总已有理论、假设、边界及其适用范围 | 理论资料、已有模型；方法说明及待核查项 | 材料实验试点不强求复杂机理推导；重要推断需要专家核验 |
| 6 仿真设计及结果 | 整理已有仿真方案、参数与结果，辅助解释 | 研究者提供的模型、真实输出；方案或结果摘要 | 首期不承诺执行仿真，不得把建议方案写成实际结果 |
| 7 实验设计与开展 | 设计变量、对照和测试，排定任务依赖与时间；收到进度和结果后更新计划、通知下一步 | 材料设备、时间约束与反馈；实验计划、通知和变更记录 | 实验由研究者执行；未知时长/资源标注假设，重大变更确认 |
| 8 数据分析 | 检查数据和单位、可复现计算、绘图、解释差异及局限 | 原始或可核验数据、字典、方法；图表和计算记录 | 不存在的数据不能生成；统计方法适用性需核验 |
| 9 组织论文 | 依研究和期刊要求形成结构、图表与各章节初稿 | 研究材料、数据、文献；可编辑 Word/LaTeX 初稿 | 允许按需分批写作；缺失内容标注，不虚构证据 |
| 10 质量审查 | 校验事实、数据、引用、方法、逻辑与创新点 | 草稿与证据；定位清楚的问题清单 | 可执行自动核验；专业争议由专家判断，不把主观偏好当硬规则 |
| 11 修订迭代 | 定点修复、补证据、跟踪版本，必要时建议补实验 | 审查意见、新资料；修订稿及变化原因 | 反馈可靠性先判断，不能仅为消除质疑而删除创新内容 |
| 12 定稿准备 | 检查格式、引用、附件和现行投稿规则，交研究者最终处理 | 已审核稿、期刊要求；导出文件与未解决项 | 首期交付目标是高质量初稿；不承诺投稿、录用或自动定稿 |

### 根据输入选择路径

- **已有实验数据**：优先整理数据、分析和证据，按需补文献，再进入写作与审查；不重走已经完成的选题与实验。
- **实验尚未开展或正在进行**：按实际情况选择文献与设计，制定任务、时间和资源计划；完成一项后记录结果，调整下一项并提醒。结果成熟后可进入论文路线。
- **只有方向和思路**：先澄清关键目标和限制，检索并提出初步方案；缺失的数据、时长、材料和设备不自行假定为事实。

### 流程的结束与回退

每项任务给出输入、输出、证据、状态和缺项；遇到文献与数据冲突定位回相关工作，必要时人工判断。并非每一步都必须人审；研究方案、重要实验变更和高风险科学判断按情形确认。导师的 12 步用于映射与检查可能遗漏，不作为测试集 12 项全通过的强制条件。

## 导师待审议事项｜论文内容深度、质量阈值与科研约束

> 状态：2026-11-10 待导师审议；**下列候选规则和提问不等于导师已经批准**。本文只汇总需裁决事项，完整计算规则和既有 12 项问题请看《论文评分.md》。科研真实数据与流程评测也需按《04-资料收集与评测规范》执行。

### 1. 先说明两类验收

- **软件验收**：可以在获授权的实验材料上完成输入→计算→初稿→来源核查→修订→导出、保存/重开，并运行独立评分和报告；功能未实现、崩溃或不可复现为软件失败。
- **科研质量验收**：八维评分、关键真实性硬门槛、学科专家对核心科学判断的裁决、内容深度和人工修改成本。软件跑通但论文得分不足或证据不够，属于**科研质量未通过**，不得合并为软件故障或强行宣称“合格”。

### 2. 导师需给出的最小裁决（可一次性审）

| 编号 | 需要裁决的具体问题 | 建议方案 / 讨论依据 | 导师决议 |
|---|---|---|---|
| T01 | 论文目标类别：研究论文、数据论文、方法论文？ | 首月先选 1 种主稿件类型，明确必需章节与方法/数据要求；不同类型不能套同一深度标准 | 待定 |
| T02 | 内容深度怎样算够？ | 按章节的「应答科学问题、必需实验事实、必要图表与对照、允许缺项」列清单，专家逐项查实，不以字数和篇幅代替质量 | 待定 |
| T03 | 缺项能否由模型推断？ | 关键参数、原始结果、机理性论断缺失时必须标注并向研究者追问；不得补造数据 | 建议禁止，待确认问询优先级 |
| T04 | 八维评分及权重是否继续沿用现有草案？ | 现有 Q/D/M/R/S/F/L/T 权重可作试验基线，先不擅自重设或删除 | 待批准 |
| T05 | 综合分通过阈值是多少？ | 在 2–3 份代表性样稿与专家试评分后决定；尚无有效阈值，不得临时填 80/90 分 | 待批准 |
| T06 | 哪些维度有最低分？ | 科研真实性、来源与计算、方法和结论宜设单维最低要求，避免总分掩盖致命弱项 | 待批准 |
| T07 | 关键科研错误的“一票否决”范围 | 以《论文评分》第 5 节为起点；确认虚构实验、数据失真、伪造引用、泄露等阻断项与复核程序 | 待批准 |
| T08 | 已知缺项时如何统计覆盖率？ | 缺必要材料不能记 N/A 后宣称完整科研能力通过；必须单列资料缺失/评测不可覆盖/软件未完成 | 待批准 |
| T09 | 首批目标期刊与文章类型 | 选 1–2 本对应实际研究方向的期刊，确定官网作者指南、稿件阶段与可编辑格式包；不要求照抄已发表 PDF 排版 | 待指定 |
| T10 | 格式偏差与科学偏差怎样扣分？ | 保留 F 专管格式、Q/D/M/R 专管事实与科学；遵循期刊 Fast Format 等明确弹性条款 | 待批准 |
| T11 | 评审角色与争议处理 | 确定性检查可自动运行；引文语义可由独立 Agent 辅审；重大创新、机理与实验安全由研究者/导师裁决 | 待批准 |
| T12 | 达标后的实际人工修订量要求 | 单独计修改分钟、轮次、重大错误，至少在同一任务与参照条件下对照，暂不宣称已达到减少多少百分比 | 待批准 |
| T13 | 动态实验计划首批确认的工艺硬约束 | 从真实材料与实验方法中取得适用标准/时长下限/设备限制；**未确认参数不允许写死为通用常数** | 待确认 |
| T14 | 主案例材料是否允许用于线上模型及 Trace | 先选择公开或明确授权数据，确认许可、数据边界、目标论文隔离与日志脱敏 | 待确认 |
| T15 | 是否采用科学研究 A0–A4、论文论证 B0–B4、Agent 自主执行 C0–C4 **三轴候选标签**？ | 仅诊断记录，不能互相折算或新增第九论文评分权重；与样本 A/B/C 和方案 C 区分 | 待批准 |
| T16 | 首批不同研究类型的目标深度及必需证据分别是什么？ | 对比较、方法、机理、数据型任务分别列证据清单，按任务目标而非统一最高等级 | 待批准 |
| T17 | 什么情况下 Discussion 的科学解释充分？ | 判断相近研究可比性、反面证据、替代解释、机理主张和适用局限；不靠字数 | 待批准 |
| T18 | 原始研究、方法、数据论文与综述如何适配章节/评分子项？ | 用稿件类型定义适用项，真实 N/A 与证据缺失 UNVERIFIED 严格区分 | 待批准 |
| T19 | 是否采用 E1–E10 实验规划与科学决策候选维度和权重？ | 先由专家标注延期、异常、失败、新结果等场景并试评，不能以论文八维直接替代 | 待批准 |
| T20 | 哪些科研解释/重要实验条件应由材料导师独立复核？ | 核心机理、创新、新对照、研究方向及危险/高风险操作需明确决策责任 | 待批准 |
| T21 | 哪些缺项与科学错误应阻断科研质量通过？ | 核心论断无证据、未经确认的新工艺、虚构实验或误引等分别说明核验与解除程序 | 待批准 |
| T22 | 评分器自身须达到何种严重错误召回、误报与证据定位水平？ | 在专家标注的正反样例上校准，按严重度设置指标，不能借用 PaperBench 排行榜当阈值 | 待批准 |
| T23 | 自动研究的停止/继续/补资料/专家升级条件如何界定？ | 依据证据收益、研究深度、许可/成本、人工决策，不按固定模型调用轮数衡量深度 | 待批准 |
| T24 | 如何衡量 Agent 相对人工科研工作的净收益？ | 固定任务/质量要求，对照严重错误、修改分钟、无效建议、总时长/费用及交付深度 | 待批准 |

### 3. 评分结果记录模板

每次报告必须输出：任务/稿件类型、目标期刊+稿件阶段+规则版本、数据包版本/许可、八维得分和逐项错因、适用项与评测覆盖率、真实性硬门槛、缺失资料问询清单、专家意见、修订版本、修改分钟、模型及工具成本、最终分类（软件通过/失败、科研质量通过/失败/未评估）。

**通过逻辑候选：** 软件必需项通过；科研质量要求所有已确认硬门槛无违规、综合分达到导师批准的阈值、核心维度满足最低要求、关键材料覆盖充足且专家争议已处置。未批准阈值前，科研质量只能报「试评分、待导师校准」，不可称达标。

### 4. 需研究者回答的业务问题与问询模板

遇到缺失输入时，不是笼统说“资料不足”。系统应说明：
- 缺什么：例如试样几何尺寸、原始载荷记录、测试速度、标准编号、样本数、图像来源；
- 为什么需要：用于哪项计算、方法复核、结果或机理论断；
- 影响什么：哪些章节和指标受阻，哪些步骤仍可继续；
- 如何补：支持上传文件、确认已有数据、明确「无此资料/暂不可提供」；
- 不提交时：保留明确的占位符/不确定性，不允许编造。

实验规划任务还应说明新增变量是否已经由研究员批准，未批准的科学实验建议不能作为工艺事实和自动触发条件。

### 5. 迭代原则

按「定位导致低分的可核验问题→最小修复→固定条件回归→记录分数和人工修改量」执行。限制自动调用次数和模型成本，避免为了提升可见总分而窥视隐藏测试答案。科研目标未达标可以继续后续阶段优化；30 天结束要保留真实的未通过状态，而不是隐瞒结果。

供导师优先审核的原稿章节：《论文评分》第 4 节八维度、第 5 节科研诚信、第 9 节原 12 个问题，以及新增第 11–12 节。

### 6. 深度与评分器校准新增审核入口（2026-11-11）

新增 T15–T24 出自 [科研工作流研究深度与质量评测调研报告](../05-研究报告与归档/01-科研深度调研报告原文.md#src-26) 第 7–12 部分，是**候选待决项**，不会自动改变原 T01–T14、论文八维权重或首月 C 级产品范围。

建议导师一次性审阅记录（结果可以部分填写，不能将空白视为默认批准）：

| 决议字段 | 需要明确的内容 | 当前状态 |
|---|---|---|
| 研究/稿件类型 | 首批任务科学问题、原始/方法/数据/综述类别、目标期刊+阶段 | 待确定 |
| 任务 A/B/C 深度 | 每个目标等级的必要产物、必需证据与明确不适用项；**不是首月方案等级** | 候选 |
| 论文分数 | Q/D/M/R/S/F/L/T 权重、综合阈值、核心维度底线、论断/内容覆盖率 | 待校准 |
| 实验评分 | E1–E10 是否采用、权重与严重错误门槛、异常后科学决策的评审者 | 候选 |
| 科研事实阻断 | 虚构/篡改数据、不能支持核心结论、错误标准/越权批准的核对与解除程序 | 待批准 |
| 评测器可靠性 | 严重错误召回、误报、定位正确率、适用项/缺项正确率与专家一致性 | 待校准 |
| 人工有效性 | 科学质量相当时的人工修正时间、成本、无效建议率与接受程度 | 待试点 |
| 生效条件 | 决议人、日期、规则版本、有效研究范围、复审日期 | 未批准 |

导师认可“科研真实”和“研究深度”的原则，不等于已批准任何数值阈值。单靠 2–3 个试例不能证明跨材料领域的泛化可靠性；需区分初期参数校准和之后的独立评价。若评审意见分歧，保留每位评审的理由和待决定事项，不用多个 Agent 一致票强行代替专家。

正式详细规则分别见 [科研深度通则](../03-科研质量与样本/01-科研深度与评测方法.md#src-11)、[论文评分](../03-科研质量与样本/02-论文评分.md#src-13) 和 [实验规划科学决策评分](../03-科研质量与样本/03-实验规划评分.md#src-14)。
