# 第一阶段实施规范｜两条并列科研路线

## 1. 入口与公共规则

新建项目时记录研究目标、研究类型、已知创新主张、现有资料、材料与设备、资源及进度、期刊和数据授权；未知项留空并按影响追问，不能编造。区分文献事实、实验事实、假设和缺失项。分配来源编号，保留原始文件、版本和可追溯位置。可从已有数据直接进入论文路线，也可从尚未完成的实验进入规划路线；同一项目可以在两条路线间往返。

按需选择步骤而非固定 12 道门槛。复核发现资料不足时定位缺项并回到相应步骤；超出资料支持范围的结论标注待核实。创新性与实验证据并重，不把审查者的主观偏好当普遍规则。

## 2. 路线 A：真实材料到论文初稿

**输入**：研究问题与目标、实验方法与关键条件、真实结果及数据字典、已有图表、相关文献和期刊要求；允许分批补充。缺少实验数据时可输出提纲或有明确占位的部分草稿，不能捏造完整结果。

**工作过程**：整理和检查数据与单位 → 检索并筛选合法获取的文献 → 核对论点与证据 → 按课题需要制定结构 → 复现或检查可计算的结果与图表 → 撰写并交叉核查摘要、方法、结果、讨论和结论 → 对事实、引用、数据和创新主张进行独立复核 → 定点修订 → 导出 Word/LaTeX 与核验记录。必要时请求研究者补充材料，既有真实数据不允许被自动覆盖。

**产出**：可编辑初稿；来源与论断对应表；数据和图表来源；待核查项、审查问题与修改记录。目标是尽量减少人工修改；不能承诺发表或少量修改即可投稿。

## 3. 路线 B：动态实验规划与进度提醒

**输入**：研究目标、研究假设、材料及工艺、候选变量与对照、设备和人员可用性、实验时长或合理区间、截止时间、安全及资源限制；已开展实验的进度和结果。未知资源、时间或科学参数明确标为待补充，不给无依据的精确日期。

**初次计划**：检索类似研究与适用方法，形成实验目标、条件/对照、步骤、数据记录要求和评价指标；划分每项任务的前置依赖、预估时长、计划时间或时间窗、负责人及设备。并行与顺序以真实依赖和资源条件判断；安排只作为建议，由研究者确认执行。明确何时根据何种结果选择后续分支，以及所依据的文献、数据或专家意见。

**执行中更新**：研究者标记完成、延期、失败、资源变化或上传新数据 → 系统核对实际状态和前置条件 → 判断是否触发结果分支或时间调整 → 生成变更前后对照、依据、受影响任务和新的下一步建议 → 重要方法变更或不确定风险交研究者确认。输入结果不等于实验已经客观完成；以研究者反馈为记录依据。

**提醒**：按已确认时间、到期事件或前序任务完成触发，提醒包含实验内容、建议开始时间/窗口、前置条件、需准备的资源和链接；进度未更新、实验条件缺失、数据矛盾或前置未完成时标记阻塞，不发送误导性“可以开始”。支持已读/确认、延后、失败重试与去重，应用内通知为首期基线；邮件或其他渠道视配置与授权接入。提醒依赖可靠的定时服务及在线状态，不保证对方已读或线下执行。

**输出**：可查看、可调整的实验计划和日程；近期应做事项；依据及缺口；变更与通知记录；可用于后续论文的数据资产。系统不代替研究者开展实验，不把计划写成已经发生的实验。

## 4. 共用能力与职责

协调核心根据任务状态调用检索、研究构思、方法、实验规划、数据、写作和独立复核等能力；A0—A7 是职责划分，不规定固定数量的模型调用。每项重要产出携带输入版本、来源、产出版本和运行记录。系统在许可范围内使用已验证的通用工具、技能和模型服务；科研任务策略、计划变更与质量规则由平台负责集成。

审查不应反复阻断正常工作：能确定的错误自动定点修复；缺来源标注并补检；涉及科学判断和实验重大变更时提出选择。任务和预算均设超时、重试和人工接管。

## 5. 30 天 V1 的工程实现要求

1. 研枢状态机保存科研业务步骤，OpenScience 管 Agent 回合。科研输入缺失时进入 WAITING_FOR_DATA；重要科学变更和授权问题进入 WAITING_FOR_CONFIRM；执行结果不确定时进入 RECONCILING，核对完产物与副作用后才能尝试恢复。
2. 证据应可关联原始来源、计算输入与脚本、论文具体论断及出处，不能用模型运行日志当学术证据；计算结果不得覆盖输入文件。
3. 材料专业规则需要标准版本、单位、适用条件及研究员批准状态；由受控代码检查强制工艺约束，实验发生延期后只重排受影响任务。
4. 论文核验应查真实数据、单位、引文是否支持论断以及图表对应关系。机理性判断保留专家参与；不能通过“多 Agent 同意”证明正确性。
5. V1 工作台运行于 Ubuntu 工作站并可从 Windows 访问；对 OpenScience 原前端做明显修改、美化、必要动效与可交互实验甘特图。支持保存任务、恢复待办、主动请求缺失实验资料、选择期刊及其稿件类型、导出 Word/LaTeX。安全、许可、模型费用、资料外发与可追溯执行观测都要留记录。

详见 [数据库设计](../04-开发规范/01-数据库设计.md)、[任务恢复](../04-开发规范/02-任务状态与恢复规范.md)、[接口契约](../04-开发规范/03-OpenScience接口契约.md)、[材料规则](../04-开发规范/04-材料实验规则与质量检查规范.md)。
