## 科研任务深度与质量评测通则 V1｜研究类型、证据、停止条件

> **状态：规范增补候选（2026-11-11）**。来源：本仓 [科研工作流研究深度与质量评测调研报告](../05-研究报告与归档/01-科研深度调研报告原文.md#src-26) 第 2、3、6、7、10、12 部分。本文负责**跨路线术语、任务契约及证据判定**；论文评分以 [论文评分](02-论文评分.md#src-13)、实验规划评分以 [09-动态实验规划与科学决策评分](03-实验规划评分.md#src-14)、案例抽样及独立 Eval 以 [04-资料收集与评测规范](01-科研深度与评测方法.md#src-12) 为准。候选等级/阈值未经导师批准，不改变 [首月 V1 目标](../02-产品与实施/01-首月V1目标与计划.md#src-6)。

### 1. 目标和四类不可混淆的评价

科研 Agent 的质量不等于“写出论文”或“执行足够多步骤”。对每个科研任务分别记录：

| 评价轴 | 必须回答 | 最小证据 | 不得混同 |
|---|---|---|---|
| 科学真实性 | 实验数据、文献、计算和论断是否真实/可靠？ | 真实数据/原文定位、脚本、实验记录、专家核对 | 软件运行成功不能证明实验真的做过 |
| 科研任务与研究深度 | 本任务科学问题是否得到要求程度的回答？ | 任务类型、核心问题、必要证据、解释边界 | 文献数量、字数和步骤数不是研究深度 |
| 科研成果质量 | 论文或实验设计是否达到相应要求？ | 论文八维或实验 E1–E10 逐项判定、专家意见 | 语言流畅不代表科学合理 |
| Agent 执行质量 | 是否可恢复、可追踪、低成本、适当自动化？ | Task/Attempt、失败日志、人工修改量、时间/费用 | Agent 更自主不代表科研成果更深入 |

成果交付报告至少区分 **SOFTWARE_FAIL / SCIENTIFIC_FACT_FAIL / SCIENTIFIC_QUALITY_FAIL / EVALUATION_INCOMPLETE / ACCEPTED**。这是**结果分类**，不是新增任务状态机；任务状态仍按 [任务状态与恢复规范](../04-技术选型与开发/03-数据运行与接口.md#src-21) 执行，硬性科研阻断单独挂在质量/交付记录。重大疑似错误先 UNVERIFIED/待核，不等于已确认违规，更不等于指控研究人员学术不端。

### 2. 科研问题—研究类型—必要证据

| 研究类型 | 科学任务/价值 | 应有证据 | 不必强制 |
|---|---|---|---|
| 信息调查/综述 | 已知、争议、研究空白与适用边界 | 可定位文献、检索范围、相反证据、覆盖盲区 | 不必每次做新实验 |
| 现象/比较研究 | 有条件的真实观测或性能差异 | 试样身份、条件、单位、对照/可比性、误差 | 不必每次证明微观机制 |
| 关联/验证研究 | 变量关系或特定可检验假设 | 统计/设计适用性、反例与不确定性、可复核结果 | 相关性不直接等于因果 |
| 方法研究 | 方法是否优于基线、何时有效 | 对照方法、误差、偏差、适用范围、成本 | 不必声称发现新材料 |
| 机理研究 | 区分竞争解释 | 机制预测、关键表征、有效对照与结果 | 不可从性能提升直接断言化学机制 |
| 数据研究 | 形成可用科研数据资源 | 数据字典、来源/许可、覆盖与缺失、质量及复用记录 | 不必强制假设驱动叙事 |
| 创新发现 | 新结论与现有研究的真实差异 | 最接近研究、可信新结果、复核与限制 | “没检索到”不等于全球首创 |

**项目任务契约**至少包含：研究目标与问题、研究类型、已确认假设/创新主张、已授权证据及缺项、预期输出、研究者批准的科学/工艺约束、目标深度及适用检查项、人工决策负责人、规则版本。可先以业务对象/文档表示，不在本文件指定数据库表或 Agent 编排框架。

### 3. 候选研究深度三轴（A/B/C，**不是** A/B/C 样本等级，也不是首月方案 C）

**A 科学研究深度**：

| 等级 | 可核验的实际工作 | 不应给该级的例子 |
|---|---|---|
| A0 信息整理 | 有出处的摘要/事实清单 | 没有真实可定位来源 |
| A1 事实核对 | 单位/试样、基本复算和研究事实可靠 | 没有检查输入条件就计算 |
| A2 证据比较 | 可比性、正反证据、现象解释与局限 | 不可比条件的性能直接排序 |
| A3 假设与方案 | 可检验假设、反驳条件、变量/对照与替代解释 | 无论何结果都宣称支持假设 |
| A4 真实验证综合 | 实际实验/独立证据、验证反馈、科研专家复核 | 仅多个 Agent 同意就声称证明 |

**B 论文论证深度**：

| 等级 | 核心证据 |
|---|---|
| B0 提纲/语言 | 未形成真实研究内容，不能宣称完整稿件 |
| B1 事实覆盖 | 主要方法与结果有可核验事实，主要偏描述 |
| B2 综合分析 | 数据/文献比较、条件范围及初步解释 |
| B3 完整论证 | 问题—方法—证据—解释—局限闭合，适用内容深度达到任务标准 |
| B4 经独立审查 | B3 且关键事实与目标稿件阶段要求经复核；仍**不保证录用** |

**C Agent 自主执行深度**：

| 等级 | 需要实际证明 |
|---|---|
| C0 基础辅助 | 文本帮助，来源和人工责任明确 |
| C1 单任务执行 | 检索/计算/写作的输出可检查 |
| C2 多步骤与追问 | 相关任务关联、缺项主动追问、状态保存 |
| C3 结果驱动与局部修复 | 异常反馈、部分重排、恢复/审批实际测试 |
| C4 受控长程编排 | 证据/预算/权限/版本跨任务持续一致 |

以上是**调研提出的候选标签，不是既有科研共同标准**。对每个任务由研究者选定目标 A/B/C 并列出逐项证据，不将三轴平均，不以 C 高推论 A/B 高。例如“方法研究”达到高质量不必证明新机理；没有论文交付的实验设计任务可以将 B 记 N/A。首月 C 级产品范围不意味着全部任务自动达到 C4。

### 4. 按科研目标选择必要流程（不规定固定 Agent 链）

| 任务入口 | 最小必要工作 | 何时扩展/追问 |
|---|---|---|
| 已有真实数据 | 原件/单位核验→复算→证据组织→论文/分析→独立复核 | 方法/样本缺失；解释超出证据 |
| 仅有部分数据 | 缺项清单＋可独立计算的部分 | 核心推断依赖缺失数据时暂停相应步骤 |
| 仅有课题目标 | 研究问题→文献和假设→可核查实验设计候选 | 重要研究方向和参数待研究者批准 |
| 有已批准计划 | 事实与依赖审查→反馈→候选局部调整 | 实际延期、故障、新结果或安全/资源变化 |
| 结果违背假设 | 查试样/仪器/单位→竞争解释→有识别力的行动建议 | 需要补对照、复测或更改方向时确认 |
| 已有论文 | 定位问题→必要的定点修订→独立复测 | 核心实验事实不可复核时升级 |
| 单个错误引用 | 原文定位/语义核查→局部修复 | 若影响核心结论，再扩展审查 |

**研究深度不是流程长度**：无证据收益的多轮讨论、重复检索、虚构假设或无差别重跑整个 Agent 链均不合格。实际 Research Agent 采用哪些 Skills/工具由任务条件动态决定。

### 5. 研究停止、追问、修订与人工升级

每次决定继续研究应能指出“要回答的未解决问题”“预期新增证据/减少的不确定性”“可用授权资源”，并留下结果：

| 条件 | 研究动作 | 结果报告 |
|---|---|---|
| 必需证据、任务深度和已批准门槛均满足 | 交付并归档 | 完成；区分软件、事实、科研质量 |
| 关键资料缺失但可补 | 具体追问并仅等待相关步骤 | WAITING_FOR_DATA 业务状态；缺项和影响清单 |
| 研究方向/重大方法/敏感权限变更 | 暂停受影响操作，列选项请研究员确认 | WAITING_FOR_CONFIRM |
| 已确认科研真实性硬错误 | 阻断对应科研成果并核实来源 | 质量 BLOCKED；任务状态另按既有状态机 |
| 缺陷可由现有证据修复 | 定点修订、保存 diff、固定条件复测 | 版本化问题和修订记录 |
| 文献检索边际收益不足 | 记录检索覆盖、关键盲区和停止依据 | 停止该检索步骤，不假称证据全覆盖 |
| 资源上限/科学争议/必须新增实验 | 暂停自动调用并向研究者呈报 | 待审核/待资料/受限退出；不凭空追加结果 |

调研报告第六部分提到的 `REVISING`、`STOPPED_NO_GAIN`、`PAUSED_BUDGET`、`NOT_ACCEPTED` 均是**候选研究结果标签**，不得直接写入已有八状态任务机而造成状态冲突。异常或失败处理的正式执行规则见 [任务状态与恢复规范](../04-技术选型与开发/03-数据运行与接口.md#src-21)。

### 6. 最小可审计质量结果和专家边界

每项任务给出研究类型、目标深度、证据清单及出处/版本、已核查/未核查/不适用项、科研事实阻断、论文/规划专项评分与覆盖率、未解决科学争议、人工决定与修改时间、执行日志/费用；评分规则版本必须可复查。

- 程序可核：数据计算/单位、文件哈希、明确约束、计划依赖、可编辑导出等。
- 独立模型可辅：引文语义支持、论证与反例疑点、必要资料缺口。
- 专家须审：核心机理/创新、研究重要性、重大设计变化和高风险行为。模型意见不得代替科研事实。

**调研报告的身份**：可作为更完整的方法论与真实材料案例索引；外部论文作者评测不是研枢性能证据；文中评分演示不是实测结果。规范获批准前的等级/阈值只能报告为候选/试评分。

## 第一阶段资料收集与评测规范

### 1. 总则

两条重点路线分开建样本和验收，同时共享可合法使用的文献、研究背景和材料元数据。先检索公开资料；实验室授权案例可增强真实任务检验，但不作为启动前提。未发表资料不得擅自上云。这里的“训练”首先指任务示例、知识检索、提示/流程改进及评测；模型微调是另一项需要数据和模型授权的决策。

### 2. 论文初稿路线需要的材料

| 材料层次 | 所需资料 | 能测什么 |
|---|---|---|
| A 完整实验案例 | 最终论文、方法与条件、原始或可核查数据、关键图表数据及数据字典 | 数据处理、论文生成和完整证据链；核对实际开放程度 |
| B 可核验案例 | 论文、补充材料、关键图表源数据或可验证数据 | 部分计算、结果解释、论证和文献核查 |
| C 写作参考 | 可合法获取的论文全文、方法和参考文献 | 结构、表达、领域术语；不能检验真实数据复现 |

优先 A/B，材料不全时仅用于能够验证的任务。审稿意见、早期稿件和完整研究轨迹均为可选；导师认为其差异大，不将其作为通用金标准。期刊档次不等于数据开放或案例质量。

### 3. 实验规划路线需要的材料

| 类型 | 输入与证据 | 任务用途 |
|---|---|---|
| 方法与计划样例 | 目标、材料、变量、对照、制备与测试方法、前置条件、设备限制、期望结果 | 初始实验设计与依赖顺序 |
| 时序与资源样例 | 时长、设备/人员可用性、截止时间、工序依赖，注明来源或专家给定的假设 | 日程可行性、冲突和通知 |
| 动态反馈样例 | 任务完成/延误/失败、结果与测量、设备不可用、研究目标变化 | 更新下一实验、条件分支、计划版本和依据 |
| 专家参照 | 专家审核的多个合理方案、不可接受错误、适用范围和分歧 | 科学合理性与选择解释；不能假设唯一标准答案 |

公开论文的 Methods、补充信息和 protocols 常可支持实验方法设计；**通常不提供实际设备日历、准确耗时和进度事件**。缺失时由研究者提供或专家基于假设构造，清楚标注“模拟/专家设定”，不能冒充作者真实进度。用同一方法材料能测试部分科学规划，但不能直接证明现实日程和通知可用。

### 4. 具体查找流程

1. 围绕异质材料粘接、复合材料制备/性能测试及课题关键词查询 [Crossref](https://search.crossref.org/)、[OpenAlex](https://openalex.org/)、期刊官网及研究者可使用的数据库。先查论文、DOI、期刊和研究类型。
2. 逐篇打开论文官方页面的 Methods、Data availability、Supplementary Information、Source Data、Code availability；跟进 [Zenodo](https://zenodo.org/)、[Figshare](https://figshare.com/)、[Materials Commons](https://materialscommons.org/)、机构仓库的链接，核对文件是否实际可获取及数据许可。
3. 下载有权使用的材料，记录论文元数据、链接、获取日期、版本、权限、图表/数据可用性、实验条件、样本限制及两路线适用范围；不能把存在“数据可用性声明”误记为数据公开。
4. 论文任务提取当时可用的研究目标、方法与数据，保留发表论文作为对照；实验任务从方法中提取可核查的流程，缺失的时间、设备与事件由专家补充假设，制作动态场景。
5. 先建立可运行的小样本池，建议探索 8–12 篇论文并争取 3–5 套有可核查数据的案例；数量是探索计划，不是质量阈值。两条路线各建立若干真实或模拟场景，专家时间不足时先从少量高质量样本开始。

### 5. 案例卡模板

记录：案例 ID / 学科与材料 / 使用目的（论文、规划、两者） / 来源与许可 / 文献和原数据链接 / 允许输入及时间点 / 隐藏参照资料 / 实验条件和缺口 / 数据字段与单位 / 时间与资源是否真实或假设 / 各次反馈事件 / 专家判分标准 / 用途分组 / 责任人与版本。案例中的真实、假设、模型生成信息必须分别标识。

### 6. 数据分组及泄漏控制

以研究案例或论文家族分组，分开发调试、固定回归、独立测试；同一案例不同阶段不可分别进入开发和独立测试。记录文献家族、数据集及相近实验的关联。论文生成时目标论文及其直接包含答案的材料不进入任务上下文，设置检索黑名单并记录检索结果；基础模型可能已见过公开文献，隔离不能消除预训练污染。尽可能引入经授权、系统此前未接触的案例独立评估。不要把缺乏真实原始数据的模拟任务描述成实验复现。

### 7. 论文路线评测

诚信底线先单列：虚构文献、编造实验或篡改关键数据属于严重失败，分数不能掩盖。其他维度由可核查规则及专家共同评价：数据与图表准确、引用真实性与论断支持、方法与结论一致、创新点保留与边界、结构语言及期刊适配。比较发表稿重在覆盖、遗漏和错误，不要求复述原文；记录可核查问题数、专家修改时间及修改量、任务耗时和费用。100 分旧量表可作为候选细则，首批案例由专家校准，不把未校准阈值写成达标标准。

### 8. 动态实验路线评测

- 初始方案：研究目标匹配、变量/对照、工序依赖、材料设备、数据采集和安全限制；科学判断由领域专家评价。
- 排程：先后依赖、设备人员冲突、工作时间、截止时间、实际/假设时长与缺项提示；给出可解释时间窗口。
- 反馈响应：对完成、延误、失败、异常数据、设备不可用分别检查下一步、局部重排、依据和版本；有分歧时记录多种合理方案。
- 提醒：时间到、前置完成、延期、取消、重启和重复事件，检查去重、失效通知撤销、失败重试与可追溯性；单次交付成功不代表已读或已做。
- 价值：专家对科学合理性、方案采纳/修改情况、重排与沟通耗时进行记录；不以贴近原作者顺序或实验结果最优作为唯一标准。

对比固定输入下的新旧系统；新增资料前后比较仅反映资料与系统共同变化，不单独证明模型能力变强。采用专家基线或人工现行做法比较；独立测试记录版本、盲测条件、模型、工具和成本。

- [材料实验数据溯源研究](https://www.nature.com/articles/s41524-019-0216-x)：实验数据与元数据管理参考。

### 10. 30 天 V1 的数据与安全验收补充

- 从 MAT-001 或 MAT-002 优先挑选一套实际下载且核验字段、单位、测试方法、许可的数据集。不得预设 MAT-002 存在所有试样的屈服强度。
- 原始来源按字节保存 SHA256。记录解析条件、转换规则和计算产物版本；float64 有舍入，Excel 原有精度损失无法靠解析器恢复。不得宣称“零精度损耗”。
- 原始输入、执行输出和隐藏答案使用权限隔离。目标论文标题、DOI 和直接答案不进入 Agent 可检索的执行范围；公开论文仍可能受到预训练污染。
- 数据或材料实验硬约束缺失时阻断对应科研计算或科学决策，不必阻断所有无关步骤。确认与复审要有状态和来源。
- Day 30 必须分别评估论文与实验规划。完成两条端到端流程只算软件 V1 验收，专家科学质量评价单列。

### 11. 与 2026-11-10 首月 C 级 V1 目标的对齐

本文件负责**样本真实性、数据分组和独立评测方法**；首月具体交付等级以 [首月 V1 决定](../02-产品与实施/01-首月V1目标与计划.md#src-6) 和 [首月计划](../02-产品与实施/01-首月V1目标与计划.md#src-7) 为准，科研内容深度与八维评分以 [论文评分](02-论文评分.md#src-13) 为准。

- **论文首月必须可测试的行为**：真实数据导入与复算、图表与主要章节证据、缺失数据时主动询问、目标期刊与稿件类型选择、Word/LaTeX 实际导出、独立定位数值及引用错误。缺重要数据只能如实呈现占位和科研质量未达标状态。
- **实验首月必须可测试的行为**：依赖无环、材料工艺下限和资源冲突检查、延期/失败/新结果反馈后的局部重排、审批前后版本差异、可交互甘特图、运行时提醒去重与重启补处理。模拟事件必须标为模拟，不能据此宣称真实实验已开展。
- **分开记录三种结果**：软件流程是否跑通、科学真实性及错误、导师认可的论文/实验规划质量。未确定的导师评分阈值不得凭经验代填，也不能将缺项标 N/A 后直接宣称论文达标。
- **时间约束**：Day 24–30 为完整七天测试周。至此未获得专家评价的科研质量应记为“待核实/待校准”，而不是自动通过；问题清单与成本应随案例一并交付。

### 12. 科研研究深度、评测器可靠性与双路线校准（2026-11-11）

本节来源于 [科研深度调研报告](../05-研究报告与归档/01-科研深度调研报告原文.md#src-26) 第 4、6–12 部分。**原 A/B/C 资料分级、开发/固定回归/独立测试隔离均保留**；[深度通则](01-科研深度与评测方法.md#src-11) 的 A/B/C 是另一种候选标签，必须写明 `sample_tier` 与 `research_depth / manuscript_depth / agent_autonomy`，不能混淆。

#### 12.1 案例卡补充字段与适用性

每张案例卡还应记录：研究类型、研究问题与可检验假设、对照/变量/可比条件、目标科研/论文深度标签、任务必需证据和评价原子项、重要反例、适用的论断/数据/Methods 子项、事实来源、哪些结果是原作者公开值 vs 独立复算值、专家可接受的多种行动选项。真实设备日历、处理时长和反馈如由专家设定必须显著标记为**模拟**。

案例可采用不同的合规材料研究类型，不要求所有样本都包含微观机理。2026-11-11 调研报告还记录两项候选：Zuo *et al.* (2026) 木质素/纤维素复合材料，DOI [10.1038/s41467-026-77206-8](https://doi.org/10.1038/s41467-026-77206-8)；Takamura *et al.* (2024) CFRP 胶接强度评价，DOI [10.3390/ma17020394](https://doi.org/10.3390/ma17020394)。**这是补充候选，不等于已下载全部 Source Data、实验记录或已归入 A 级**；原 MAT-001/002 优先验收规则不变。

#### 12.2 评价对象、流程和证据

| 评价对象 | 证据及执行 | 不能替代 |
|---|---|---|
| 科学事实 | 原始记录/版本/文件哈希、单位计算、引文原文定位、专家复核 | 不能以模型“认为真实”替代 |
| 研究任务深度 | 事前冻结的研究类型、科学问题、必需证据和等级检查 | 不能按字数、步骤、Agent 数量 |
| 论文质量 | [Q/D/M/R/S/F/L/T](02-论文评分.md#src-13) 子项、覆盖率及硬门槛 | 不能用格式与语言高分抵消科研错误 |
| 实验设计和决策 | [E1–E10 候选](03-实验规划评分.md#src-14)、异常分支与专家可接受行动集合 | 不能只检验日历和甘特图 |
| Agent 运行 | 状态、恢复/重试、审批、安全、成本和研究者修改时间 | 不能以科学论文评分代替软件验收 |

**独立评价最小过程**：冻结任务/规则与授权输入 → 定适用项和期望证据 → 产生科研产物 → 程序复算/约束检查 → 独立证据/逻辑复核 → 专家解决科学争议 → 逐条报告 PASS/PARTIAL/FAIL/N/A/UNVERIFIED/BLOCKED → 定点修订（限次）和同条件回归 → 隐藏集独立评测与版本归档。这是检查项目的逻辑组织，**不要求对应十二个 Agent 或固定调用链**。

统一 `criterion_id`、`research_type`、`required_evidence`、`applicability`、`scoring_unit`、`severity`、`primary_criterion_id`、`evidence_locator`、`reviewer`、`rule_version`、`human_approval`；必要证据缺失应为 UNVERIFIED 而非 N/A，已确认严重违规另设阻断门槛。

#### 12.3 评测器自身必须接受独立评测

在已知答案的标注数据中注入：错单位、错误计算、错试样组、虚构 DOI、真实但不支持论断的文献、合法转述、过度因果解释、缺关键工艺条件、未经批准的实验版本和错误资源占用。记录严重错误召回/漏报、误报率/精确率、错误位置准确率、claim-source 支持判断、同条件评分一致性、适用项 N/A/UNVERIFIED 准确性。

科研专家至少对代表性正确、错误和争议样例独立标注，必要时计算适用的 κ、ICC 或 Krippendorff α；阈值需导师校准。**PaperBench 和 AstaBench 的既有分数不能直接成为材料科学领域通过线**。目标论文及其直接答案不得进入生成 Agent 的检索上下文；预训练污染仍需在报告中注明。

#### 12.4 科研质量演示与真实测试严格分开

- **浅层完整论文**：即使章节、语言、格式齐全，若缺相反证据、重要对照和可检验的 Discussion，也应在 Q/R/S/M 的具体适用细项显示缺陷；调研报告第 11.1 节 `73.75` 为人为造分的说明例子，**不是实际评分**。
- **真实数据但 Methods 缺失**：8 个同权细项中 5 PASS、1 FAIL、2 UNVERIFIED，则覆盖率 6/8 = 75%，可判断细项的示例通过比例 5/6≈83.3%；完整论文质量应记待评估。
- **实验异常分支**：给定假设不符、变异与质量不确定的情景，专家允许多种合理下一步，并判断每种行动的证据、信息价值和成本；具体用例见 [规划评分](03-实验规划评分.md#src-14)。

科研论文取得高分、实验规划建议被导师偏好、模型自评一致，均不能推论实际实验已完成或系统具备普适科研发现能力。

#### 12.5 人工基线、投入和结果分轨

与具有可比研究条件的人工基线比较：严重错误数、科研目标/深度条目通过、达到研究者接受稿件的实际实质修改分钟、修改轮次、实验规划人工改动任务数、无效建议率、总执行时间、模型/工具费用。若无有效基线，不得声称节省一定百分比。

**每次验收结论必须区分**：软件流程是否通过、科学事实是否可靠、研究深度是否达任务目标、论文或规划质量是否达到已批准标准、Agent 可靠性和成本。未批准质量阈值或缺专家证据时为“试评/未完成评价”，不得自动通过。

调研来源中关于论文 Methods、研究伦理、标准适用域和评测器校准的不同证据等级，可从 [原始调研报告第十五部分](../05-研究报告与归档/01-科研深度调研报告原文.md#src-26) 的 R01–R20 索引回查。
