# 研枢科研智能体平台｜材料实验论文初稿量化评测细则 V1（导师审阅稿）

**适用范围**：第一阶段「真实材料实验数据 → 尽可能高质量、减少人工修改的论文初稿」；兼用于检验文献检索、分析、审查及修订能力。  
**文件用途**：作为 `04-资料收集与评测规范.md` 的补充附件，不替代已有 A/B/C 案例分类、开发/回归/独立测试隔离及动态实验规划专项评测。  
**状态**：**建议草案；权重、阈值、细则未获导师批准**。未经试测，不将分数解读为“可发表概率”。  
**来源口径**：第 1 节复述项目既定规则；第 2 节给出检索核实的成熟评测思路；第 3–10 节为**研枢自拟的操作细则**，第 11–12 节为 2026-11-10 已记录的需求补充，第 13 节是 2026-11-11 调研候选增补。后述科研内容深度、执行条目与阈值均须区分真实证据、专家意见和研枢自拟建议，不能误当既定批准标准。

---

## 1. 已有规定与本次需要补足的缺口

现有 GitHub `04-资料收集与评测规范.md` 明确：

- 资料按 **A（完整实验案例）/B（可核验实验案例）/C（写作参考）**分级，优先 A/B；缺哪些资料，就不能声称能验证哪些能力。
- 测试集分 **开发集、固定回归集、独立测试集**，同一个论文家族及其数据不能跨组；目标论文不能成为相应生成任务的可见输入。
- 论文路线需要审查：科研诚信、数据/图表、真实引用与证据支持、方法及结论一致、创新点保留、结构语言、期刊规则；另外记录人工修改时间、耗时和费用。
- 旧版 **100 分论文评分表可作候选，需用首批材料实验案例由专家校准**，尚未具备每项可直接计算的执行细则。

**本次新增**：8 个一级维度（每项先算 100 分）及权重、明确计数单位与分母、格式规则包、逐字引文检查、自动与专家协作评分、硬性失败判断、诊断输出与导师确认项。

**原则**：不为了论文形式凑满导师 12 步；只评估当前任务真实要求的结果。标准答案应来自授权真实数据、可靠原文及专家确认的关键要求，而非仅凭“最终论文长得像不像”。

## 3. 评分架构：每个维度独立 100 分，最后汇总

| 一级维度 | 记号 | 维度得分范围 | 建议总分权重 | 评审来源 |
|---|---|---:|---:|---|
| 文献引用与论断证据 | Q | 0–100 | **20%** | 原文定位＋程序比对＋人工核查 |
| 实验数据、计算与图表 | D | 0–100 | **20%** | 原始记录＋复算＋图表检查 |
| 实验方法与可复核性 | M | 0–100 | **15%** | 条件/变量/对照表＋领域专家 |
| 科研结论与创新点 | R | 0–100 | **15%** | 数据证据＋确认的创新清单＋专家 |
| 结构完整与逻辑论证 | S | 0–100 | **10%** | 任务要求＋专家标注 |
| **目标期刊格式合规** | F | 0–100 | **10%** | 目标期刊官方规则包＋程序检测 |
| 学术语言、冗余与规范 | L | 0–100 | **5%** | 规则工具＋专家抽检 |
| 文件交付、证据及修订可追溯 | T | 0–100 | **5%** | 文件解析＋任务/版本日志 |
| **总计** |  |  | **100%** |  |

**综合分（科研诚信门槛另行判定）：**

`Final = 0.20Q + 0.20D + 0.15M + 0.15R + 0.10S + 0.10F + 0.05L + 0.05T`

每个维度的 100 分不是“主观打一个整数”，而是该维度的子项按以下口径加权：

`维度得分 = 100 × Σ(适用子项权重 × 子项通过比例) / Σ(适用子项权重)`

- **N/A**：任务类型确实不适用，比如不需要直接引文时，“逐字引文准确率”不适用。按适用项重新归一化，并显示哪些条目未适用。
- **MISSING（缺输入）**：本应提供原始实验数据但没有提供，**不能算作 N/A 后仍宣称已验证数据能力**；应输出“该维度未评估 / 只能部分评估”的覆盖率。
- **FAIL（应交付却缺失）**：输入材料齐全且任务明确要求的功能没做，应视为未通过，不能以 N/A 回避。
- 每个分数同时呈现**评测覆盖率**，不允许仅展示总分。综合分只有在核心 Q/D/M/R 得到足够证据后才报告为完整论文得分；覆盖不全时标记“部分任务评分”。
- **首批不要给出“80 分合格、90 分顶刊”这类阈值**。先让专家盲评少量样稿，校准分数与严重错误处理方式。

## 4. 八个维度各自怎样计满分 100 分

### 4.1 Q：文献引用与论断证据（100 分，综合权重 20%）

| 子项 | 满分 | 实际计数办法 |
|---|---:|---|
| Q1 参考文献身份真实 | 15 | **可确认的真实文献条目 / 受检文献条目**。查 DOI、题名、作者、期刊及版本；不存在、指向其他文章或关键字段冲突计失败。 |
| **Q2 逐字直接引文准确** | **15** | `100 × 逐字正确条数 / 应检直接引文总数`，其中应检总数覆盖**任务要求与实际出现的全部不同引用位置**；漏写的必需引文也计入分母。一条中任意汉字、数字、术语或可见标点与原文不一致，该**整条计 0**。需检查页码/原文位置与上下文。不要求直接引文的实验论文标 N/A。 |
| Q3 论断真正被所引文献支持 | 30 | 每条 **claim–source 配对**判断：充分支持 1、部分支持 0.5、不支持/冲突 0；逐项平均。核心结论发生冲突另触发严重错误审查。 |
| Q4 应引用论断覆盖 | 20 | `100 × 有充分有效证据引用的必要论断数 / 所有应引用论断数`；少写、漏写也要纳入任务必需事实覆盖检查，防止靠少引用刷分。 |
| Q5 引用精确性与相关性 | 10 | `100 × 相关且有用的有效引用次数 / 受检引用次数`，识别错位、堆砌及虽真实但与该句无关的引用。 |
| Q6 证据定位与版本可追溯 | 10 | `100 × 可回到原文页/段/图表及原始版本的关键论断数 / 受检关键论断数`；仅 DOI 存在但无法核对应有结论，不能算支持。 |
| **合计** | **100** | |

**Q2 是你提出的严格“十句引用错一句扣十”的标准**。当测试任务**专门考核 10 条逐字引述**时，专项总成绩就是 **90/100**；当评估**整篇论文**时，必须同时检查文献真实性、论断支持和引用覆盖等其他因素，Q 维度不只由逐字引文决定。两类报告单独展示，不可混为一谈。

**例 1：明确要求逐字引用 10 句。** 有 9 句与原文完全一致，1 句仅改变了一个汉字或一处可见标点 → `逐字引文专项分 = 9/10×100 = 90`。若其他 Q 子项均为满分，那么在本建议加权模型中 Q 维度 = `98.5/100`，该错误令整篇综合分下降 `0.30` 分；审查清单仍逐条列出该错误。**若老师认为这个处罚偏轻，可提高 Q2 权重、单设直接引文准确率门槛（例如必须 100%）或按严重程度阻断交付。门槛应与综合分独立明确，不能暗中扩大扣分。**

**例 2：使用文献做转述而不是逐字引用。** 原文研究结论是“特定处理条件下强度提高”，稿件写成“在相同条件下该处理有助于增强材料强度”，若证据与限制一致则 **Q3 可得满分**，不能因为词语不同当作幻觉。反之，把“部分样本”“特定温度”“可能”变成“所有样本”“任意温度”“必然”，即使只改一两个词也可能造成实质性误引，**Q3 扣分**；数据/关键结论不实再触发独立复核。

**重要执行细节**：

1. 测试集先标记每条属于 `VERBATIM`（原样引述）、`PARAPHRASE`（转述）、`DATA_CLAIM`（数据性陈述）、`UNCITED_REQUIRED`（应该有引文却缺失）。不允许模型自己决定“这句话无需检查”。
2. 对 `VERBATIM` 保留原始出处的固定版本、页/段位置和确切文本；采用 Unicode 字符比较；可去除 PDF 抽取产生且人工核准的**不可见控制字符**，**不得自动忽略标点、汉字、数字与词语差异**。排版/断行导致的文字识别歧义交人工复核，避免错扣。
3. **逐字正确但删去关键上下文**同样可能产生歧义，须另外接受 Q3 支持关系评测，不能因字符串一致就算科学正确。
4. 若引文无法合法获取或源文件无法可靠解析，标 `UNVERIFIED` 并核实，不能静默算作通过，也不得自动断定作者故意造假。
5. 直接引文并不是材料实验论文越多越好；优先**准确转述＋正确引文**，仅在确有必要时逐字引用。不得为取得 Q2 高分故意生成大量引用句。
6. 辅助指标单独报告 `引用覆盖率/引用有效率/F1`，而不是用总分掩盖少量极严重的虚假引用。

### 4.2 D：实验数据、计算与图表（100 分，综合权重 20%）

| 子项 | 满分 | 量化方法 |
|---|---:|---|
| D1 关键原始数值一致 | 35 | 按**关键数值事实**逐项核对原始数据/经批准计算结果，正确数 ÷ 应检数；误差容忍度由单位、测量精度和事先固定的四舍五入规则定义。 |
| D2 单位、条件、有效位数 | 15 | 逐条核查数值所对应单位、样本条件、有效位数；错单位、组别、测试条件计不通过。 |
| D3 计算与统计可复核 | 20 | 有输入、代码或公式、参数、计算输出可重现的关键计算项 ÷ 应核验计算项。 |
| D4 图表与源数据一致 | 20 | 逐图核对坐标、图例、数据点/趋势、组别、图注、来源，符合项目数 ÷ 图表检查总项数。 |
| D5 不确定度与样本信息 | 10 | 样本量 n、重复次数、误差表示、异常值处理、局限披露满足已确定规则的项 ÷ 必需项。 |
| **合计** | **100** | |

**示例**：某实验稿有 20 个事先列出的关键数值，19 个正确 → D1 通过率 95%，D1 得 `35×0.95=33.25/35`。但如果错误属于样品强度单位 MPa 被写成 kPa，即使只有一项也要额外列为**重大错误**，不能仅用平均分掩盖。

### 4.3 M：实验方法与可复核性（100 分，综合权重 15%）

| 子项 | 满分 | 量化方法 |
|---|---:|---|
| M1 材料、样品及测试条件覆盖 | 20 | 逐项核对实验样品、制备方法、关键设备/条件；已标注的必需项目覆盖率。 |
| M2 变量、对照组与采样合理性 | 25 | 各关键变量、对照、样本/重复设置及偏差来源，由导师预标注检查表计通过率。 |
| M3 实验步骤可复核 | 25 | 是否交代足以理解并按许可复核的方法、参数、测量步骤；缺必需项按项扣分。 |
| M4 分析/统计方法适用 | 20 | 对照分析方法的前提、统计检验与数据类型；由脚本验证可计算项，专家评价适用性。 |
| M5 方法假设与限制披露 | 10 | 理论前提、适用范围、已知偏差和不确定性是否被妥善说明。 |
| **合计** | **100** | |

**注意**：实验类不强制做复杂机理推导；没有模型、仿真要求时不得扣“没有复杂理论公式”的分。老师 12 步是方法参考，不是 12 个必须出现的章节。

### 4.4 R：科研结论与创新点（100 分，综合权重 15%）

| 子项 | 满分 | 量化方法 |
|---|---:|---|
| R1 关键结论的真实证据覆盖 | 30 | 所有必需结论逐一对应真实数据/可核验文献，有依据计 1，证据不充分计 0.5，无依据计 0。 |
| R2 结果解释无越界 | 25 | 不能把相关性说成因果、局部条件说成普遍结果、观察说成已证实机理；按专家标注关键论断检查。 |
| R3 **研究者确认的创新点保留** | 20 | `100×被准确保留的已确认创新点 / 必须保留的创新点`；不得为顺从模型评审随意删除有证据的贡献。 |
| R4 与已有研究的差异对比 | 15 | 必需对比维度（对象、方法、结果、条件等）覆盖与依据是否完整。 |
| R5 局限与适用范围 | 10 | 任务中需说明的实验局限、外推范围、待核实事项是否正确披露。 |
| **合计** | **100** | |

**边界**：没有充分文献覆盖时，不能自动断定“世界首次”；发表稿自己的创新表述也不是无需核验的唯一答案。

### 4.5 S：结构完整与逻辑论证（100 分，综合权重 10%）

| 子项 | 满分 | 量化方法 |
|---|---:|---|
| S1 必需章节完整 | 25 | 对选定稿件类型的必需章节清单逐项检查；不是机械出现 12 个导师步骤。 |
| S2 研究任务与关键信息覆盖 | 25 | 任务卡预定事实、方法、图表和创新贡献在正文中是否有合适位置。 |
| S3 章节间论证连贯 | 25 | 背景—问题—方法—结果—讨论—结论是否衔接，专家对预标注逻辑缺口计数。 |
| S4 摘要、图表与正文一致 | 25 | 摘要中的关键数字/结论是否与正文相符，图表是否被恰当解释、编号与正文一致。 |
| **合计** | **100** | |

### 4.6 F：目标期刊**格式合规**（100 分，综合权重 10%）

**先确定 `目标期刊 + 稿件类型 + 检查阶段（可编辑初稿 / 初投稿 / 修订稿） + 官方指南访问日期`。** 不能只根据“顶刊已发表 PDF 的字体和分页”判定初稿格式是否合格。

| 子项 | 满分 | 量化方法 |
|---|---:|---|
| F1 期刊和文章类型识别正确 | 10 | 名称、投稿类型、所用规则版本正确，稿件阶段匹配。 |
| F2 标题、摘要、关键词要求 | 15 | 官网对字数、数量、位置、必备内容有**明确要求**时逐项检查；无硬约束不自行发明。 |
| F3 节标题及内容顺序 | 15 | 按该稿件类型的必需章节与顺序逐项检查，允许官方许可的等效结构。 |
| F4 参考文献**格式** | 15 | 作者列表、年份、题名、卷期、页码、DOI 表达、文内编号和参考文献表一致；与 Q1“文献是否真实”分开。 |
| F5 图、表、补充资料编排 | 15 | 图表编号、引述顺序、标题、图注、补充材料命名与已确认指南一致。 |
| F6 公式/单位/符号排版 | 10 | 公式编号、图内符号、上下标、单位样式、数学字体/LaTeX 宏等格式规则。 |
| F7 必需披露与声明栏目 | 10 | 例如数据可用性、利益冲突、作者贡献、AI 辅助说明（以目标期刊现行要求与当前阶段为准）。 |
| F8 文件技术合规 | 10 | 文件格式可编辑，若交付 LaTeX，编译无致命错误；若提交 Word，图表、引用和公式没有丢失。 |
| **合计** | **100** | |

**建议把期刊规则存成一份可自动执行的「格式规则包」，而非写死为一条通用提示词**：

```yaml
journal: Nature Communications
article_type: Article
stage: initial_submission
source: https://www.nature.com/ncomms/submit/how-to-submit
verified_at: YYYY-MM-DD
rules:
  - id: format-abstract
    target: abstract
    check: journal_specific_requirement
    severity: major
  - id: format-reference-order
    target: bibliography
    check: citation_numbering_and_required_fields
    severity: minor
  - id: format-data-availability
    target: declarations
    check: required_if_applicable
    severity: major
exceptions: [allowed_first_submission_flexibility]
```

此段 YAML **仅为平台规则结构样例**，不是声称 Nature Communications 官方要求了某一固定摘要数字。实际数字应从实时作者指南提取、保存页面快照/版本并由开发者复核。

**三组格式参照（均应按目标期刊当期官网重新核对）**：

| 参照期刊 | 已核对的实际特点 | 平台落地 |
|---|---|---|
| **Nature Communications** | 初投稿对整体格式有弹性，但要求稿件材料完整；论文修订/交付时对章节、参考文献、数据可用性等有具体要求 | `journal/nature_communications/article/{draft,submission,revision}`；优先校验必需声明与完整性，不误罚初投稿可容许的排版差异 |
| **ACS Applied Materials & Interfaces** | 使用 ACS **Fast Format**；初投稿参考文献可采用不同样式，但应完整；具体稿件类型、图表和补充资料有要求 | `journal/acs_ami/article/{draft,submission,revision}`；如官方允许任意一致样式，不应扣“不是最终期刊排版”的分 |
| **Advanced Materials Interfaces** | 官方指南列有摘要、关键词、图表以及统计报告要求，且区分稿件类型 | `journal/adv_materials_interfaces/research_article/*`；按正式要求逐项可测 |

**教师待确认**：第一批究竟选择哪 1–2 本期刊作为目标格式？如尚未指定目标期刊，用“材料实验论文通用完整性清单”评分，并将**特定期刊格式**标记 N/A，不能虚称“符合 Nature/ACS 投稿要求”。

### 4.7 L：学术语言、冗余与规范（100 分，综合权重 5%）

| 子项 | 满分 | 量化方法 |
|---|---:|---|
| L1 专业术语准确且一致 | 25 | 预定义重要术语/缩写出现处检查是否一致、准确。 |
| L2 语言表达科学严谨 | 25 | 区分观察、推断、假设；避免含混或不当绝对化措辞；按有依据问题计数。 |
| L3 内部重复与冗余 | 25 | 对正文按语义片段查重复，结合必需重复（如摘要/结论）由专家判定，不以普通词汇重现直接扣分。 |
| L4 与已有文献的不当重合 | 25 | 正式的文本相似性工具辅助，人工确认引用、常用术语、方法习惯表述的合法性与是否涉及不当复制；**不设置“一定低于多少相似率就合格”的武断值**。 |
| **合计** | **100** | |

### 4.8 T：文件交付、证据与修订追溯（100 分，综合权重 5%）

| 子项 | 满分 | 量化方法 |
|---|---:|---|
| T1 关键结论的证据记录完整 | 30 | 每个关键论断的文献/实验源、来源 ID、版本与核验状态可查询。 |
| T2 运行日志与人工审批可追溯 | 20 | 关键任务步骤、工具、权限、确认结论与版本存在必要记录。 |
| T3 定点修改与回归安全 | 20 | 规定错误能修复，同时不意外篡改原来正确的关键数据/结论。 |
| T4 文件完整与再打开 | 20 | Word/LaTeX 与图表附件可打开、可编辑，内容未丢失。 |
| T5 未解决事项明确交付 | 10 | 无证据、尚待补实验或专家审批的内容明示，不能伪装成已完成。 |
| **合计** | **100** | |

**避免重复扣分**：Q1 判文献身份，F4 判参考文献的排版；D4 判图表数值，F5 判图表编号/版式；R1 判科研论断真实性，S4 判摘要和正文的一致性。同一错误可以触发“科研诚信门槛”，但**不得在同一子项中重复记同一条失败**。

## 5. 科研诚信硬性门槛（总分之外）

以下内容一旦由可信证据或人工复核**确认**，标记 `BLOCKED`，**即使综合分很高也不得通过**：

1. 把没有开展的实验、仿真或测量写成真实已完成的工作。
2. 捏造不存在的参考文献、DOI、关键实验数据，或将他人论文的数据冒充项目自身数据。
3. 擅自更改原始数值/组别/关键条件，导致关键结论失真。
4. 核心研究结论与真实证据直接冲突，仍以肯定方式陈述且不披露。
5. 未经许可泄露保密材料，或评测时读取被隔离的目标论文/隐藏答案。
6. 无依据删除或重写研究者已经确认的关键科研事实、创新贡献。

**轻微标点错误与实质学术造假不可同级处理**：逐字引述一处标点不同应严格扣 Q2，但通常不直接触发 BLOCKED；“更改一个词把无效变有效、把没有数据说成已有数据”则可能构成严重科研事实错误，应复核升级。

所有 `BLOCKED` 均需记录原文位置、核对依据、严重性、人工确认状态；**仅由 LLM 猜测的“疑似幻觉”不得直接作为已确认违规**。

## 6. 从源文件到分数：具体评分流水线

1. **定义任务和适用范围**：论文类型、目标期刊、是否要逐字引文、是否交付真实完整结果、期刊规则版本。为关键结论、必要方法、图表、引文建立 `expected_items` 清单。
2. **冻结输入与答案**：执行端只能拿到研究目标、授权实验材料、当时可用文献；最终论文及专家答案由独立 Eval 保存。保存文件指纹、来源、许可和测试集组别。
3. **解析输出**：将 DOCX/LaTeX/可解析 PDF 映射成章节、句子、引用标记、表格、图例、公式、参考文献表；原文/数据定位尽可能使用结构化 XML、真实电子表格而非只靠 OCR。
4. **确定性验证**：文献元数据/DOI、数值/单位、表格计算、引文精确字符串、编号/章节、文件能否编译和打开。记录每个错误的 `item_id`、位置和对照依据。
5. **证据支持判断**：将论文论断和原文/实验资料建立逐项映射；必要时用独立模型辅助判断“完全支持/部分支持/不支持/证据不足”，高风险项交导师或研究者复核。
6. **专家核查**：创新、实验设计、统计适用性和科研结论边界由材料领域专家对标注样本确认。比较专家之间的一致程度，先校准自动评分器。
7. **统计报告**：生成八个维度分、综合分、评测覆盖率、硬性门槛、每条错因及可定位链接；不可只给数字不留证据。
8. **修订与复测**：相同输入和相同评分规则比较版本 V0、V1；固定回归集不得用来反复窥视答案；盲测集只用于阶段性验证。

### 6.1 简化案例：格式如何定量扣分

假设目标期刊在所选稿件阶段有 20 条已确认的等权**适用格式规则**，其中 18 条通过、2 条失败：

`F = 18/20 × 100 = 90/100`。

若细化为 F1–F8 有不同权重，则按第 4.6 节各项适用规则通过比例计算。**同一论文不应因期刊容许的初投稿格式差异被扣分**。

### 6.2 简化案例：一个论文综合得分

| 维度 | Q | D | M | R | S | F | L | T |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 假设维度分 | 92 | 95 | 84 | 86 | 91 | 90 | 88 | 90 |
| 加权占比 | 20% | 20% | 15% | 15% | 10% | 10% | 5% | 5% |

`Final = 18.4 + 19 + 12.6 + 12.9 + 9.1 + 9 + 4.4 + 4.5 = 89.9/100`。

**结果展示**应是：`89.9/100（建议模型）｜待导师校准｜无已确认硬性失败｜评测覆盖率 XX%｜人工修改 120 分钟（演示占位值）`，**不是**“89.9 分代表达到顶刊质量”。

### 6.3 给老师看的“可审计问题清单”格式

| item_id | 维度 | 原文位置 | 具体问题 | 对照证据 | 处罚/结果 | 处理状态 |
|---|---|---|---|---|---|---|
| Q2-001 | 逐字引文 | 引言第 3 段 | 原句一处标点不同 | DOI / 版本 / 页面定位 | 该引文 0/1；Q2 分项下降 | 待确认 |
| Q3-002 | 引文支持 | 讨论第 2 段 | 将特定条件改成所有条件 | 原文指定段落 | 不支持、需要改写 | 待修订 |
| D2-003 | 数据单位 | 图 2 图注 | MPa 写成 kPa | 原始数据表列、单位 | 重大错误，需专家确认 | 阻塞 |
| F4-004 | 参考文献格式 | 参考文献 8 | 编号次序不符合本目标期刊规则 | 期刊指南链接及访问日期 | F4 项失败 | 待修订 |

这只是**人工构造的演示错误**，不代表已对现有候选论文运行过上述检查。

## 7. 人工修改工作量：单独统计，不夹入论文科学质量

由于平台第一阶段核心目标是**尽可能减少人工修改**，这项指标应高优先级展示，但不宜在没有人实际修稿时强行计算成“论文质量分”。

建议固定同一任务与质量要求，比较：

| 指标 | 定义 | 建议记录方式 |
|---|---|---|
| `time_to_acceptable` | 从初稿交付至导师认可“可继续投稿准备”的**有效人工修改分钟数** | 实际计时，剔除单纯等待、实验补做耗时或另列 |
| `revision_rounds` | 完成一次评审→修改→再次确认的轮次 | 版本记录 |
| `critical_errors_remaining` | 修订后仍未解决的重大科研错误数量 | 专家逐项核查 |
| `substantive_edits` | 涉及数据、方法、引用、结论、创新的实质修改数量 | 人工标注 Diff |
| `time_saving` | 同难度人工基准耗时与 AI 辅助耗时的变化 | `(人工基准 - AI辅助) / 人工基准 ×100%`；缺基准写“未知” |
| `failure_rate` | 中断、答案污染、文件坏损、越权的频率 | 每次运行记录 |

首批样本极少，不宜拿一篇测试的人工修改时间断言平均节省多少百分比。**质量未达标而“修改时间很少”不是正向成绩**。报告应同时给出质量、严重错误、时间和成本。

## 8. 自动评分与专家评分怎样分工

| 检查类别 | 建议执行方式 | 风险控制 |
|---|---|---|
| DOI/作者/题名、章节、编号、格式、精准字符串、数值算术、LaTeX 编译 | **程序规则优先** | 处理版本、Unicode、OCR 误差、期刊特殊条款；错误有可复核日志 |
| 文献语义支持、实验解释、逻辑连贯、重复表达 | **独立模型辅助＋人工抽查** | 与执行模型尽量分开；不可把 LLM 的自信度当准确率 |
| 重大创新、实验设计合理性、复杂统计及机理、核心结果争议 | **导师/领域专家裁决** | 记录专家对分歧的说明，不强行让两个评审给相同评分 |
| 整体论文质量与人工修改负担 | **匿名样稿专家评审＋实测修改时间** | 尽量隐藏稿件来源，减少“AI 写的/人写的”偏见 |

评分器本身需要先评测：用已标注的“10 条真实引用、10 条改错引用、10 条转述”作为最小检查样本，报告**误报率、漏报率和定位准确率**。这是一个启动实验建议，不是成熟项目的官方阈值。

## 10. 执行前仍需落实的材料（可直接分给数据收集人员）

对每个 A/B 实验案例，尽量保存：`研究目标/任务卡`、`原始实验数据和字段/单位字典`、`实验方法与条件`、`最终论文及 DOI`、`图表源数据`、`来源和许可`、`与任务相关的种子文献`、`可供独立 Eval 查看但 Agent 不可见的标准对照`。

对**格式评测**额外保存：目标期刊的**官方作者指南网页/版本及核验日期**、一到两篇**同稿件类型的已发表论文（仅作内容/结构示范）**、本次是初稿/投稿/修订的标记。

对**逐字引文评测**额外保存：在合法权限内可核对的**来源精确片段**、页段/图表位置、版本及标注。避免把受限全文或大量原文片段写进对外共享的测试包。

首轮可从已有材料实验候选集中选择 2–3 个数据完整案例运行，先测试评分脚本和专家一致性，再推广到 8–12 篇候选。不要因为很多论文缺审稿记录就把样本判废；审稿意见不作为本评测的普适金标准。

## 11. 论文内容深度、主动补资料与首月具体交付（2026-11-10 决策补充）

**与原有八维评测的关系：** 本节明确“主要章节初稿”实际应包含什么，**不新建另一套综合评分权重**。Q/D/M/R/S/F/L/T 的子项和原 12 项导师审议问题仍是主规则；新增的章节深度和补资料行为作为可量化检查清单，分配到现有 M/R/S/Q 等项目，避免重复扣分。综合阈值、分项下限、适用稿件类型仍须导师批准。

### 11.1 交付目标与深度定义

目标是**主要章节均有实质内容**的可编辑材料实验论文初稿，科学资料不足时允许明确标示缺项，但必须主动向研究者提出准确的补资料请求。没有资料不能编造任何实验、测量、工艺、图像或参考文献；只写出章节标题不算完成有据初稿。

| 章节/内容 | 首月最低深度检查 | 需要研究者主动补充的典型缺项 | 对应原评分 |
|---|---|---|---|
| Title/Abstract | 题名回应科学问题；摘要只概括有实证支持的目标、方法、主要结果与结论 | 缺研究问题或关键结果时标待完成，不能用推测数值填充 | S1/S4、F2、R |
| Introduction | 问题背景、现有证据、研究空白/假设、本文目标及引用位置可追踪；创新主张区分已证实与待核 | 缺研究动机/相近文献/已确认创新贡献时追问 | Q、R、S2/S3 |
| Methods | 材料、试样与对照、工艺关键参数、实验设备、测试方法/条件、统计口径足以让研究员核对 | 标准编号版本、试样尺寸、加载速度、环境、样本数等 | M1–M3、D |
| Results | 至少由经过校验的**真实数据**支持的核心结果，图/表、误差/样本数与正文对应，数值可复算 | 原始数据、单位、离群处理口径、图表源文件等 | D1–D4、S4 |
| Discussion | 分析趋势与约束，区分可解释现象与推断机理；与可比文献正确对照，指出局限和替代解释 | 机理证据、形貌、控制实验、不可比条件时请求补材料 | Q3、R、M、S3 |
| Conclusion | 不超出真实结果支撑范围，回扣研究目标和局限，不将研究建议冒充实验发现 | 核心结论存在争议时请研究员判断 | R、S |
| 参考文献/图表/声明 | 文献与论文内论断关联，图表索引与来源完整；稿件类型需要的数据许可/披露可核查 | 原文不可得、授权缺失、目标期刊声明栏目需要补充 | Q、F、T |

**导师需确认**：不同稿件类型的必需章节及内容覆盖是否相同；若测试样本仅为数据论文或方法论文，不能强制要求它写成假设驱动的机制论文。

### 11.2 主动问询的验收行为

当模型遇到缺失或相互矛盾的科研材料时，输出**具体、最小且有优先级**的询问：缺什么字段或资料、影响哪个计算/图表/章节、为什么必须补、可接受的来源形式，以及缺失时能继续做什么。把“暂不可提供”保存为状态，并保留有明确占位的初稿版本；不得为了减少人工干预而生成看似合理的实验数据。

验收用至少三个故意缺项场景：**缺关键单位、缺实验工艺参数、缺支持机理的文献/测量**。需要分别确认是否精确追问、暂停受影响步骤、允许其他独立工作继续，并在补齐后只修订对应部分。缺资料被研究者确认为不可提供时，明确报告可评估覆盖率而不是把缺项误当 N/A 取得虚高分。

### 11.3 质量与覆盖率的多维结果

报告至少独立展示：
1. **内容覆盖率**：已由真实材料支持且达到任务深度要求的必需内容项数 / 本次任务应交付的内容项数；不得仅按“章节标题数量”计算。
2. **资料完备率**：必需输入中已提供且通过验证的项 / 本次应提供的项，说明无法提供和授权受限的项。
3. **论断支持率**：抽检或全检的论断中，经证据和人工规则判为支持的项 / 适用的受检论断；争议项单列。
4. **八维原评分**：分别报告 Q/D/M/R/S/F/L/T、综合分、实际评测覆盖率和错误定位；重大科研真实性错误独立 BLOCKED，不被平均分抵消。
5. **实际修改成本**：到研究员接受稿件为止的实质修改时间、轮次和重大未解决问题；未发生真实修改不能估算节省比例。

这五项不是五张新的独立评分表。将前三项映射到 S/M/R/Q 的已定义子项并保留诊断原始计数，避免同一缺项同时多次扣分。

### 11.4 首月目标期刊选择与格式规则

论文任务建立时可选择**目标期刊 + 稿件类型 + 稿件阶段（初稿/初投稿/修订）**。格式检查和导出只能使用该组合当前适用的规则版本；保存官方作者指南 URL、核对日期、规则来源与例外。生成稿件应给出应用了哪个样式包和未满足哪些期刊条款。

首月要求用户可在至少**两个经核对的配置**之间选择并看到具体格式差异；第一批哪两本期刊由研究员/导师决定（第 9 节原已有 Nature Communications、ACS AMI 等候选，不代表已批准）。通用默认稿件类型可以提供，但不得宣称符合某特定期刊。目标期刊未提供可用官方规则时，只能标「格式未验证」而不是自动猜测规则。

Word 与 LaTeX 必须是可编辑文件，使用成熟的参考 DOCX 样式、CSL 引文样式、LaTeX 模板或格式转换工具，不要求自研导出器。导出后检查标题/摘要、正文顺序、引文、图注、公式、参考文献、声明及文件可打开/可编译情况。期刊允许 Fast Format 或初投稿格式弹性时，不可按最终排版模板误扣分。

参考实现依据（非正式选型决定）：https://pandoc.org/MANUAL.html （reference-doc、--csl、--template）。

## 12. 达标阈值、循环优化与软件/科研双轨结论

### 12.1 不允许自行捏造质量目标分数

当前八维权重是**导师审阅草案**。综合通过阈值、关键单维最低分、允许缺项的覆盖率、是否必须达到某种期刊审稿水平，均应由导师在正式样本试评分后审批并版本化。未审批前可运行评分与修订，但结果标「试评分/目标待批准」，绝不能声称“达到 90 分要求”或“达到 SCI 期刊水平”。

**推荐导师审议顺序**：先确定稿件类型和本项目科研必需内容，再看 2–3 个有原始材料的试例分布、专家误报漏报及人工修改负担，再审批综合分及分项下限；严禁根据某一次模型输出临时降低阈值。

### 12.2 未达标后的迭代

按照「固定输入/评分规则版本 → 独立评分报告 → 分类问题（缺资料/证据错误/计算错误/结构深度/格式/表达） → 最小修复 → 同条件回归 → 新版本评分」迭代。优先修正确定性错误和主要科学风险，随后改善论证与表达；需要新实验数据、科学争议或研究方向决策时停在人工确认，不应靠多轮 LLM 辩论虚构补足。

运行必须设超时、最大迭代次数和调用成本上限；如果到 Day 30 仍未达到导师批准阈值，如实标记**科研质量未通过**，保留完整问题清单并继续后续优化。不得无限调用 Agent、自改评分或接触隐藏评测答案以追求分数。

### 12.3 软件失败和科研质量失败分离

| 类型 | 判据示例 | 处理 |
|---|---|---|
| 软件失败 | 工作流不能保存/重开、计算不可复现、导出文件损坏、来源丢失、规则没有执行、权限隔离失败 | 修复代码或集成，回归后复测 |
| 科研质量失败 | 软件正常但论文事实/论断/内容深度/引用/创新等没有达到导师批准要求 | 定位科研证据或模型/Skill/流程问题，补资料与定点修订，必要时专家判定 |
| 待评估 | 必需实验材料缺失、专家未完成校准或阈值尚未审批 | 记录覆盖不足与待决项，不得当作达标 |

专家问题合并入口：《导师待审议事项.md》。现有《论文评分》第 9 节 12 个问题仍保留，新增深度/阈值问题不取代原问卷。

## 13. 科研深度、评分分母和独立评价器校准增补（2026-11-11，导师审阅候选）

> 来源：[2026-11-11 研究深度调研报告](../05-研究报告与归档/01-科研深度调研报告原文.md#src-26) 第 4、7、8、10、11 部分。**本节补充原 Q/D/M/R/S/F/L/T 体系，不新增第九个总分维度、不变更现行候选权重，也不批准新阈值。** [科研深度通则](01-科研深度与评测方法.md#src-11) 负责 A/B/C 三轴标签，本文件仍是论文评分的唯一计算与逐项评价入口。

### 13.1 内容深度与原子项一一映射

每个具体科学问题先有任务卡：研究类型、研究问题、必需证据、已确认创新主张/限制、适用章节、目标期刊与稿件阶段。逐章判「论证是否回答了什么、证据在何处、尚存何种替代解释」，不能用字数、引用条数、标题数量或文风替代。

| 具体检查 | 主计分归属 | 检查依据/浅层错误 | 相邻维度避免重复计分 |
|---|---|---|---|
| 科学问题及本文目标是否明确 | S2，必要时 R4 | 有研究问题、约束、现有研究差异；只有泛泛背景为不足 | Q4 只评价必要论断的引用覆盖 |
| 文献综合和反面证据 | Q3/Q4，相关创新比较另在 R4 | 文献是否针对相同材料/方法/环境可比，是否遗漏实质反证；罗列摘要不等于综合 | 仅当研究主张确实过度推广才另评 R2 |
| 实验设计是否具有识别力 | M2/M3 | 变量、对照、必要样本与反例能否回答问题；只有实验组没有有效比较为不足 | D3 评价计算复算，不重复扣设计缺陷 |
| 数据分析是否充分 | D3/D5 | 可复算方法、变异/不确定性、异常处理与统计前提；只报均值且应报误差为不足 | M4 评价“方法是否适用”，D3 评价“是否执行正确” |
| 解释、竞争假设和机理边界 | R1/R2/R5 | 观察与因果分离，解释与证据配套，处理局限与竞争解释 | 事实性引文支持只在 Q3；条件性越界归 R2 |
| 章节整体论证闭合 | S3，摘要一致性在 S4 | 问题→方法→结果→讨论→结论相互对应 | 单个基础错误不在所有章节自动重复扣 |

例：一处图表单位算错主要记 D2/D4；如果由此还产生了独立的错误核心科学结论，R1/R2 可以另计其**不同的科学后果**。每个缺陷有唯一 `issue_id`、`primary_criterion_id`、关联的其他判据与是否构成硬门槛，禁止同一事实错误被机械重复扣多次。

**按论文类型适配**：实验研究、方法研究、数据论文、综述的必需内容不同。数据论文不因缺少因果机理自动扣 R2，方法论文侧重与基线比较/误差/适用范围；若稿件类型确实不适用某条则记录 N/A 和批准的适用性理由。通用 IMRaD 仅为参考；具体期刊指南与适用测试标准须核对版本。现有第 11.1 节逐章检查表保持有效，本表细化评测映射。

### 13.2 统一计分状态和覆盖率；原 MISSING 的操作定义

| 状态 | 证据条件 | 计分/覆盖 |
|---|---|---|
| PASS | 可信资料表明完全满足 | 计入适用、已覆盖及得分 |
| PARTIAL | 可核验，按事先的检查规则只部分满足 | 计入适用和已覆盖，按已批准的比例得分 |
| FAIL | 可信资料表明应交付的内容未做到或明确不满足 | 计入适用和已覆盖，按失败规则计分 |
| N/A | 对本次**实际研究与稿件类型**真正不适用 | 说明原因、从适用分母排除 |
| UNVERIFIED | 应核验但来源缺失、权限不足、证据或专家判断未齐 | 计入适用分母，**不当作通过、不暗改为 N/A** |
| BLOCKED | 可信证据或研究者确认严重科研真实性/权限错误 | 在分数外阻断受影响成果的质量通过 |

原第 3 节的 `MISSING` 是**资料缺失的原因标签**，实操通常产生对应细项 `UNVERIFIED`；若“已具备材料而系统未完成明确任务”，应记 FAIL 而非 UNVERIFIED。对明显凭空编造的具体结果，确认后记 BLOCKED，不得因为资料缺少而轻描淡写记缺项。

在**同一维度或一组预先冻结的适用细项**上同时显示：

- **已覆盖项试评分** = `100 × Σ(已覆盖适用项权重 × 预定义通过比例) / Σ(已覆盖适用项权重)`；
- **评测覆盖率** = `Σ(已覆盖适用项权重) / Σ(全部适用项权重)`；
- **全部适用项质量判定**：只有覆盖率达到导师批准的标准、核心条目没有未核实且通过适用硬门槛时才能给“完整质量通过”结论。

例如 8 个同权 Methods 必需项，5 PASS、1 FAIL、2 UNVERIFIED：已覆盖 6/8 = **75%**；已覆盖项的演示通过率 5/6 ≈ **83.3%**；**不代表 Methods 整体已达标**。其中百分比为人工设定的演示情景，并非研枢实际得分或正式质量阈值。

现有第 3 节八维公式仍沿用；各维度样本量、适用性及覆盖率未满足要求时只能输出**部分任务评分**，不可对缺少的核心 Q/D/M/R 维度用其他维度平均补分并宣称总分通过。论文内容覆盖率、原料完备率、论断支持率继续按第 11.3 节作为诊断指标，不形成新的并列加权总分。

### 13.3 论文深度评审的实际检查与修订

| 对象 | 科学上要回答的问题 | 应有证据与失败例子 |
|---|---|---|
| Abstract | 实际解决了什么问题、方法/主要结果/结论是否一致？ | 与 Results 和数据一致；虚构“显著提高”或超出统计支持须拦截 |
| Introduction | 哪个具体研究空白值得研究、与最接近研究差别在哪里？ | 相关/反面文献、检索限制；只有引文列表而无差异分析不够 |
| Methods | 何种变量/对照与测量能够回答问题，别人如何复核？ | 试样、工艺、关键条件、标准版本、统计口径；缺关键速度/环境须追问 |
| Results | 真正观察和计算了什么，误差/数据质量如何？ | 原始数据、单位、脚本、图表与样本映射；不得隐藏不利组别 |
| Discussion | 结果支持什么解释，哪些机制/替代解释未排除？ | 可比研究、反证/表征、边界；仅强度提高不能证明化学键合变化 |
| Conclusion | 论断是否回扣研究问题并有条件限制？ | 结论与证据逐一关联；不可推广到未实验条件 |
| 附件/声明 | 怎样重查图表、引用、数据来源与许可？ | 可定位 DOI/页段、脚本与文件版本、期刊当期适用规则 |

定点修订遵循“问题分类→固定证据→最小改动→新版本独立复测”；无新证据时不要为了增字数或更高文字流畅度强行延长科研推断。

### 13.4 评测器自身的独立验证

评分系统的正确性须先于自动“质量通过”：

| 评测器能力 | 度量 | 起步样例 |
|---|---|---|
| 严重错误发现 | 召回率与漏报率，按严重度分层 | 错单位、假 DOI、虚构实验、错试样组 |
| 误报控制 | 精确率、误报率 | 正确转述、真实但措辞不同、复杂合法条件 |
| 定位能力 | 句/图/单元格定位准确度 | 已人工标注的图注和原始 CSV 范围 |
| 文献语义 | 支持、部分支持、反驳、证据不足 | claim–source 正反例 |
| 一致性 | 固定条件重复运行、与导师标注一致性 | 多评审者复核、κ/ICC/α（视数据类型选择） |
| 适用项处理 | N/A 与 UNVERIFIED 的正确区分 | 故意隐藏关键实验参数 |
| 泛化性 | 开发/固定回归/独立隐藏集差异 | 按论文家族严格分组 |

**正式阈值尚未批准**，不得把参考项目（例如 PaperBench）的任务复现分数直接当材料论文质量线。标准答案、原论文及可直接泄漏结果的材料不能进入本任务生成 Agent 的可见上下文。抽样和隔离机制详见 [资料收集与评测规范](01-科研深度与评测方法.md#src-12)。

### 13.5 论文质量通过的必要条件（不是串行 Agent 数量）

`QUALITY_ACCEPTED = 科研事实与诚信硬门槛通过 AND 核心证据覆盖通过 AND 任务目标深度满足 AND 专家争议已处理 AND 已批准的综合分/核心单维阈值满足`。

这些是并列判定条件，不能解释成必须串行调用五个 Agent。各阈值、适用稿件类型、例外和批准版本由导师确认，现阶段仅试评，不预设具体数字。

**软件失败、科学事实失败、科研质量失败和评价未完成应分开报告**。原第 5 节硬门槛需基于具体证据或研究者核对后确认；模型检测到异常先留待核，不得直接把研究者标记为学术不端。研究诚信定义可参考 [ORI 官方说明](https://ori.hhs.gov/definition-research-misconduct)：诚实错误和观点分歧不等同于正式科研不端。科研质量未达标时仍按第 12.2 节限次修复、回归和专家升级，不无限自评刷分。
