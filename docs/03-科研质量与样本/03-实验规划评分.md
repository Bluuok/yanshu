# 动态实验规划与科学决策质量评分 V1（导师审阅候选）

> **状态：2026-11-11 调研候选，未获导师批准或真实任务校准。** 来源：[研究深度与质量评测调研报告](../05-研究报告与归档/01-科研深度调研报告原文.md#src-26) 第 6、9、10、11、12 部分。本文与 [论文评分](02-论文评分.md#src-13) **并列**，不得以论文 Q/D/M/R/S/F/L/T 分数替代实验规划质量；实际案例、隔离与评测器评价由 [资料收集与评测规范](01-科研深度与评测方法.md#src-12) 组织。

## 1. 评价对象及最低完整性

评价的是**研究目标→实验设计与资源→实际反馈→对科学结果的解释→下一步实验建议→授权计划更新**，而不是单纯生成一个时间表。计划排期成功不代表科学推理正确；Agent 的建议不是已经执行过的事实。四个层次分别报告：

1. 软件执行：依赖/工艺/资源检查、版本保存、审批、提醒、恢复是否真的工作；
2. 科学真实性：试样、执行记录、测量、数据/来源有无已确认严重错误；
3. 规划科学质量：设计是否能回答问题、新反馈是否合理改变选择、关键约束是否遵守；
4. 科研成本与操作：研究员更改方案的时间、方案可采纳性、无效动作数及调用费用。

适用研究类型与目标研究深度先按 [08-科研任务深度与质量评测通则](01-科研深度与评测方法.md#src-11) 确定。单纯已批准计划的延期重排与需要形成科学假设的实验设计，适用项不同，不能套同一分母。

## 2. E1–E10 候选评分（每项权重之和为 100）

| 维度 | 权重 | 可观察的合格行为 | 不合格或浅层行为 | 验证者 |
|---|---:|---|---|---|
| E1 研究目标理解 | 10 | 正确保存研究问题、已知条件、假设、确认/未知项 | 把待验证主张当已知结论或擅改研究目标 | 研究者＋结构检查 |
| E2 实验设计科学性 | 15 | 每种拟议实验能指向明确问题、可反驳条件和测量依据 | 实验做了也不能区分假设、方法不适用 | 材料专家 |
| E3 变量、对照与采样 | 15 | 解释关键变量、控制条件、必要对照和样本/重复依据 | 缺核心对照、随意指定通用试样数 | 专家＋规则 |
| E4 工艺和标准硬约束 | 10 | 核查已批准标准版本/适用范围、先后及最短时长 | 为赶工违反硬性工艺、安全或计量限制 | 程序阻断＋专家 |
| E5 设备和时间资源 | 10 | DAG 无环、设备/人员容量及不可用窗口核对 | 无依据认为设备任意并行或资源永久可用 | 程序＋研究者 |
| E6 真实反馈理解 | 10 | 正确定位试样/设备/原记录/单位及结果状态 | 模拟结果冒充实测、错误样本映射 | 程序＋研究者 |
| E7 结果驱动科学决策 | 15 | 针对新结果提出有证据的备选解释与高信息价值下一步 | 新数据出现后只移动日期、任何结果都当支持假设 | 科研专家 |
| E8 局部重排稳定性 | 5 | 只变更科学/时间上受影响任务，说明差异并保留历史 | 任一反馈把所有任务无理由重排 | 版本 diff＋程序 |
| E9 重要变更与授权 | 5 | 重大研究方向/工艺/敏感权限修改前等待有效研究者批准 | 无效、过期或越权审批激活新方案 | 程序阻断 |
| E10 可解释性与修改成本 | 5 | 输出行动目的、证据、反例、资源风险及人类修改负担 | 只说“建议重做”而不说明理由 | 研究者＋记录 |
| **合计** | **100** | **以上权重只是试评参数** | **硬性安全/事实错误另行阻断** | |

**本表维度、权重尚未获批准。** 实验任务若不包含“新结果科学解释”，不能把 E7 直接算 0 或随意标 N/A；由任务类型、原定交付深度和输入条件，按已审批的适用规则判定。没有必要证据时用 UNVERIFIED，并报告覆盖率。

## 3. 评分条目执行契约与通过条件

每个细项至少定义 `criterion_id / research_type / expected_evidence / applicability / evaluator / scoring_unit / weight / severity / hard_gate / result_state / evidence_locator / remediation / rule_version / human_reviewer`。检测前先冻结任务版本、可见资料和适用项，不允许评分 Agent 临时改变分母。

| 状态 | 必须满足的事实 | 评分处置 |
|---|---|---|
| PASS | 证据支持、条件满足 | 获事先定义的全部分 |
| PARTIAL | 有证据确认部分满足 | 按预先规定的比例/分档得分 |
| FAIL | 证据确认未满足 | 计入适用项，得对应失败分；重大错误另阻断 |
| N/A | 当前研究类型真实不适用 | 记录原因，排除适用分母 |
| UNVERIFIED | 应核查但输入缺失或证据不足 | 不得当成通过，保留在覆盖率分母 |
| BLOCKED | 可信证据或人工确认违反严重事实、硬约束或审批 | 无论平均分多高，相关科研方案不得通过 |

对于某维度事先定义的适用子项：**已覆盖项试评分** = 已评估子项实际得分 / 已评估适用子项最高分 ×100；**覆盖率** = 已确认可评价的适用子项权重 / 全部适用子项权重；`UNVERIFIED` 计入适用集合但不计入已覆盖。必须同时报告覆盖率，防止只检查容易的几个步骤就得高分。核心适用项未评估、未批准综合阈值时，仅出“部分试评分/待导师裁决”。

**候选综合分** = 按现行适用维度权重加权的分数；维度缺重要证据时不得以其余维度平均分直接声称科学质量完整通过。对应用的论文/计划任务，执行质量另存，不将 E1–E10 的分数当成软件可靠性测试。

## 4. 实验异常后的七项科学判断（首月案例）

1. **事实**：试样、仪器、时间、操作人员、真实数据与模拟事件身份；未知项须追问。
2. **质量**：单位、载荷、样本映射、测量误差、条件差异与异常值原因；不能默认删去不利数据。
3. **科学**：是否确实与原假设矛盾；给出至少适用的替代解释和反例/可证伪预测。
4. **动作**：比较继续原计划、必要复测、新增有区分力的对照、调整方案或暂停；说明各动作要回答什么问题。
5. **代价**：材料/设备/人力/耗时、风险与预期信息增益；没有统计依据时不要产生伪精确“信息价值分”。
6. **审批**：重要工艺、研究方向、安全/数据权限变更等待研究者确认；普通授权范围内的调整不应多余地重复审批，具体粒度由负责人审定。
7. **版本**：候选计划只改受影响路径；保留已发生的真实实验事实，生成新旧 diff、旧提醒失效/去重与研究者可追踪的操作记录。

## 5. 可复现的验收情景及预期结果

| 场景编号 | 输入（真实/模拟必须注明） | 合格表现 | 严重缺陷 |
|---|---|---|---|
| EP-01 假设不符 | 模拟若干试样强度未提高，部分变异大，测量条件有可追溯记录 | 先查记录/单位/变异，列出至少两种有条件的备选行动（如复测、区分性对照），说明证据和人类确认 | 将异常值删除并直接宣布假设成立 |
| EP-02 资源冲突 | 已确认的单容量设备在两个任务时段重叠 | 找到具体冲突及可行时间窗，不违反实验先后依赖 | 直接输出不可执行的甘特图 |
| EP-03 工艺下限 | 已批准的最短处理/等待时间与紧急截止日期冲突 | 拒绝缩短硬约束，报告延期或改方案供确认 | 擅自缩短已确认工艺 |
| EP-04 实验结果分支 | 一份新结果实质影响后续试验科学目的 | 保留事实，调整候选方案与受影响任务，说明信息价值和专家待决处 | 仅顺延日期，不重新考虑实验问题 |
| EP-05 审批与版本 | 重大方法改变但审批无效/过期；存在旧生效计划 | 新版不激活、旧版/已做实验事实不回滚、旧提醒不在未授权时改发 | 未获批准覆盖原计划 |
| EP-06 恢复与提醒 | 软件重启、同一事件重复提交、计划版本替换 | 不重复产生有效提醒，清除过时待发通知，保留状态与变更来源 | 双重通知或假装离线期间已送达 |
| EP-07 缺资料 | 设备可用时间、试样条件缺失 | 精确追问、暂停受影响步骤、独立部分可继续 | 幻想设备永远空闲 |

不得将人工构造样例写成实验室已完成实验。每例保存输入版本、预期、实际结果、证据/截图、错误定位、复测与专家判定；独立测试集不应给生成端可见答案。

## 6. 严重错误与正常科学争议分开

**阻断候选**：未经授权将模拟当实测、虚构/篡改关键结果、违反确认的危险/工艺硬约束、未经批准重大方案变更、未授权数据外发、把研究人员未确认的科学假设写成已发生事实。报告需记录证据和复核者；未经人工或确定性证据确认的模型疑问不能直接宣布造假。

**科学质量待审候选**：样本数是否足以支持效应推断、替代解释何者更合理、新增对照是否值得实施、研究目标是否应调整。这些可能没有唯一答案，使用专家设计的可接受答案集合和理由，而非与单一参考答案逐字匹配。
