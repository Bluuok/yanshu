# 材料实验规则与质量检查规范 V1

状态：材料试点规则接口；标准参数及其适用性必须经研究员或专家确认。
示例配置：[examples/material-rule.draft.json](examples/material-rule.draft.json)。

## 规则与执行分离

规则配置保存 rule_id、rule_version、材料类别、试验方法、标准编号与版本、单位、适用条件、强制级别及批准状态。JSON Schema 负责结构合法性；具体数值必须由受控 Python 科研函数、试验方法与专家批准共同约束。不能仅因 JSON 可解析就认定科学正确。

- STRICT：已核实且适用于当前条件的工艺或安全约束。违反时阻断相关步骤；缺关键证据进入 WAITING_FOR_DATA 或 WAITING_FOR_CONFIRM。
- WARNING：提示可调整的推荐条件，不使整个项目停止。
- REQUIRES_CONFIRM：存在多种合理方法或科学判断争议时，请研究员选择并保留依据。
- DRAFT：规则未经批准，不参与自动硬阻断。任何自动使用 DRAFT 数值作为真实标准都属于错误。

实验任务使用 DAG 保存真实依赖。排程前检查依赖环、仪器冲突、人员资源和有效时间窗；硬约束不可因截止期缩短。延期时只重新计算受影响后继任务，保留旧计划和变更原因。预留试样比例与统计展示方式应按实验方法和专家意见配置，不设置通用的 20% 或 n<10 硬阈值。

## 数据读取与精度

1. 以字节形式保存原始 CSV/Excel/PDF 和 SHA256、大小、来源、权限与版本；原始文件不覆盖。
2. CSV 可按显式编码、分隔符、dtype=str 读取并关闭不需要的默认 NA 推断；记录解析参数。读取出的字段文本不等同于原始字节，不能用解析后字符串替代原始文件哈希。
3. 使用受控、显式的字段映射、单位和缺失值处理逻辑。测量值可按方法选 float64 或 Decimal。float64 会有二进制舍入，不能声称转换零损耗。
4. Excel 中超过其可表示精度的数字不能通过读取库恢复；发现异常需提示提交原始仪器输出。
5. 核对源文件哈希、数据行数、标识列、单位、有效值数量及关键字段统计。清洗结果另存，记录转换方法及可复算脚本。

## 材料专业检查

- 力学数据处理以实际试验方法为准，确认消隙段、拟合区间、失效样本和统计口径，不统一写死某一应变区间。
- 文献横向比较必须标注材料配比、制备状态、环境及测试方法；不可比较时注明限制。
- 图表必须与计算数据对应，不能用未标记平滑掩盖真实测试点；样本量和不确定度按期刊及研究设计展示。
- 机理性论断需要对应力学结果、微观表征或合适的文献依据。断口模式属于证据，不把 AF 变 CF 视为所有胶接性能提升的必要条件。
- 复审输出包含问题类型、涉及数据或原文位置、严重度、适用规则版本、自动核验结果及需要专家裁定之处。DOI 存在并不等于引用支持结论。

## MAT-002 首轮样本

MAT-002 是候选数据集，不假定已下载并逐文件核验。先检查公开的应力应变曲线、测试方法、拉伸强度、弹性模量和失效分类等可用字段，再按实际文件制定评测。不要强制要求不存在或不适用的屈服强度。

测试使用独立的输入目录与仅评测端可见的答案目录。目标论文标题、DOI 和答案不可被 Agent 通过检索或附件读到；公开论文存在预训练污染风险，不把隔离视为纯盲测保证。
